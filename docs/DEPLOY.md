# 接入与发布说明

## 一、域名白名单（必须）

小程序 `my.request` 只能请求**已在支付宝开放平台配置的域名**。本项目用到：

| 域名 | 用途 | 是否 https |
|---|---|---|
| `fund.eastmoney.com` | 基金净值查询、详情（pingzhongdata） | 是 |
| `push2.eastmoney.com` | 指数 / ETF 实时行情 | 是 |
| `fundsuggest.eastmoney.com` | 基金名称搜索 | 是 |

配置位置：**支付宝开放平台 → 我的小程序 → 开发设置 → 接口域名（request 合法域名）**，
每行一个域名，不带路径。

> 若开发者工具报「不在白名单」：开发阶段可在
> **详情 → 本地设置 → 不校验合法域名** 勾选（仅开发用，上线前必须取消并配置白名单）。

## 二、备案（上线前置）

小程序上架前需完成**支付宝小程序备案**，材料可用 DSH 插件同款《建站方案书（个人）》，
经营内容可写：

> 小程序提供基金行情查询与持仓管理服务，包括大盘指数与基金公开行情浏览、
> 个人基金持仓记录与盈亏跟踪，不涉及资金交易、支付或收集用户金融账户信息。

同时需要：
- 主体为**个人** → 支付宝个人主体小程序（无需企业资质）
- 若涉及「资讯/理财」类目，可能需要额外资质材料（如《增值电信业务经营许可证》或
  由持牌机构提供内容），以平台审核意见为准

## 三、发布步骤

1. 支付宝开发者工具 → 上传（填写版本号与描述）
2. 开放平台 → 版本管理 → 提交审核
3. 审核通过 → 发布

## 四、隐私与合规要点

本项目**不采集任何用户个人信息，也不联网传输用户数据**：

- 持仓、自选、分组、净值缓存、密码哈希全部写入 `my.setStorageSync`（仅本机）
- 「PIN 码锁」是本地的轻量遮挡，密码以**哈希**形式存储（`utils/store.js#hash`），
  非加密，仅用于防止他人随手查看；它**不是**安全加密存储，不适合存放高价值信息
- 「万能密码」同理：最多 6 个 8 位数字密码，仅存哈希（`ft.masterPwds`），
  用途是本机 PIN 遗失时仍可解锁；同样**不是**加密存储
- 网络请求只用于获取公开行情数据，请求体不包含任何个人数据
- 因此**不需要**声明收集用户信息；但建议在「关于」页面说明数据存储位置与用途

## 五、已知限制

1. **PIN 码是本地遮挡而非强加密**：清缓存/换手机即失效，数据也随之清除
   （万能密码同样存于本机，换机后不生效；可在设置页导出 JSON 备份后在新机导入）
2. **净值有延迟**：盘中为基金公司披露的上一日净值；今日净值通常晚间公布
3. **接口稳定性依赖第三方**：东方财富接口变动时需同步调整 `utils/api.js`
4. **基金库需逐步积累**：本地基金库在「搜索基金」「添加持仓」时自动入库，
   首次使用只有演示数据与内置指数/ETF 清单；用设置页可查看与导出
5. **无跨设备同步**：换手机需要重新录入（或用设置页的导出/导入 JSON 功能）

## 六、可选增强

- **导出/导入**：把 `listHoldings()` 导出为 JSON 文本，粘贴到另一台设备导入
- **真支付宝账号登录**：需引入服务端做 auth_code → openid 换取 + 会话签发，
  届时可实现多设备云同步
- **后台净值同步**：`my.onNetworkStatusChange` / 定时器在应用后台刷新净值缓存
